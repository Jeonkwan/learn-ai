Lesson 0007 • Embeddings & Vector Geometry

Embeddings Demystified

How text becomes high-dimensional coordinates, measuring semantic angles, and using Vertex AI.

In traditional DevOps and software architecture, you search text using string matching or inverted keyword indexes (like Elasticsearch or SQL LIKE '%smurfing%'). But keyword search fails when a suspect uses subtle euphemisms—such as writing "facilitation consulting gratuities" instead of "foreign bribery".

To capture meaning rather than exact words, we use Vector Embeddings. What are they mathematically, and how do they work in production?

The Geographic Coordinates Analogy

Think of GPS coordinates on Earth. A GPS coordinate is a 2-dimensional vector: [Latitude, Longitude]. Because locations are mapped to numbers, you can easily compute the distance between New York and London using basic geometry.

An Embedding Model does the exact same thing, but instead of physical locations, it maps meanings; and instead of 2 dimensions, it uses 768 dimensions (in Google Vertex AI's text-embedding-004) or 1,536 dimensions (OpenAI).

Sample 768-Dimensional Coordinate Output:
[ 0.0241, -0.0519, 0.1034, 0.0082, -0.0871, ..., 0.0415 ]

In this 768-dimensional space, concepts that mean similar things are placed geometrically close to each other, even if they share zero identical words.

The 3 Geometric Distance Metrics

When searching for the closest chunks to an investigator's query, vector engines calculate distance using one of three mathematical metrics:

1. Cosine Similarity (The Industry Standard)

Measures the angle (θ) between two vector arrows pointing from the origin, ignoring the length of the arrows.
Formula: cos(θ) = (A • B) / (||A|| × ||B||)

  • +1.0 → Vectors point in the exact same direction (identical meaning).
  • 0.0 → Vectors are perpendicular (orthogonal / unrelated topics).
  • -1.0 → Vectors point in opposite directions (polar opposites).

2. Dot Product (Inner Product)

Multiplies corresponding dimensions: A • B = ∑(Ai × Bi). Computationally much faster on CPUs than Cosine because it avoids square roots and division.
Pro-Tip: When embedding models produce unit-normalized vectors (length = 1.0), Dot Product is mathematically identical to Cosine Similarity!

3. Euclidean Distance (L2)

The straight-line ruler distance between two coordinate points: d = √∑(Ai - Bi)2. Commonly used in computer vision.

Calling Vertex AI text-embedding-004 via curl

Here is how a backend or batch worker generates an embedding in Google Cloud:

curl -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json; charset=utf-8" \
  "https://us-central1-aiplatform.googleapis.com/v1/projects/${PROJECT_ID}/locations/us-central1/publishers/google/models/text-embedding-004:predict" \
  -d '{
    "instances": [
      {
        "content": "Wire transfer disguised as luxury yacht maintenance invoice.",
        "task_type": "RETRIEVAL_DOCUMENT"
      }
    ]
  }'
GCP Specific: The `task_type` Parameter
Vertex AI text-embedding-004 allows setting task_type:
  • RETRIEVAL_DOCUMENT: Used when chunking and indexing your archive files.
  • RETRIEVAL_QUERY: Used when embedding the investigator's search question.
This asymmetric encoding tunes the vectors for maximum search precision.
