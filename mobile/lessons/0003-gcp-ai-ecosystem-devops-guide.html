Lesson 0003 • GCP AI Foundations

The Google Cloud AI Ecosystem

A DevOps map of Vertex AI, Document AI, and BigQuery Vector Search.

As a DevOps engineer managing Google Cloud Platform (GCP), you already understand VPCs, Cloud Storage (GCS), GKE clusters, and IAM policies. But when product teams ask for "AI search over banking documents," you are suddenly confronted with a flurry of Google brand names: Vertex AI, Document AI, Model Garden, Vector Search, Matching Engine, and Gemini.

This lesson cuts through the marketing and gives you an exact architectural map of Google's AI services, how they communicate, and how they map to infrastructure you already know.

Deconstructing the GCP AI Portfolio

Document AI

Cloud Document AI

DevOps Analogy: A specialized serverless OCR and computer vision microservice.

Role: Turns messy scanned PDFs, customs invoices, and bank statements into machine-readable text while keeping table structures intact.

Key Resource: Processors (e.g., OCR_PROCESSOR, FORM_PARSER_v2).

Foundation Models

Vertex AI Model Garden

DevOps Analogy: A managed model registry and API gateway (like Artifact Registry for neural networks).

Role: Exposes managed endpoints for Google's models (Gemini 1.5 Pro, Gemini 1.5 Flash) and embedding models (text-embedding-004) via REST and gRPC.

Vector DB

Vertex AI Vector Search

DevOps Analogy: A distributed, in-memory spatial index cluster (formerly called Matching Engine).

Role: Hosts multi-million vector datasets on dedicated Google infrastructure, executing Approximate Nearest Neighbor (ANN) search with sub-5ms latency.

Data Warehouse

BigQuery Vector Search

DevOps Analogy: Adding spatial index functions directly into your existing SQL analytical warehouse.

Role: Lets you run cosine similarity searches directly inside standard SQL queries using VECTOR_SEARCH() without moving data out of BigQuery.

IAM & Security: How Services Authenticate

In GCP, your workload identity or Cloud Run service account needs precise permissions to interact with these AI services. Avoid blanket Editor or Owner roles:

  • roles/documentai.apiUser: Allows a service account to send documents to Document AI processors.
  • roles/aiplatform.user: Allows invoking Vertex AI models (Gemini and text-embedding) and querying Vector Search endpoints.
  • roles/storage.objectViewer: Grants read access to raw PDFs in your ingestion GCS bucket.
DevOps Command-Line Check
You can inspect available Vertex AI foundation models directly from the command line using your existing gcloud SDK: 
gcloud ai models list --project=$PROJECT_ID --region=us-central1
