Unstructured Data & AI Retrieval Glossary

Standardized terminology for vector pipelines, knowledge graphs, and hybrid retrieval.

This glossary provides the exact operational definitions used throughout our architecture sessions. Grounded in both enterprise cloud deployment and financial crime investigation workflows.

Unstructured Data
Information that does not adhere to a predefined data model or relational schema. Includes free-text investigative notes, suspicious activity reports (SARs), scanned PDF disclosures, and email transcripts.
Chunking
The deterministic process of splitting long documents into discrete, semantically coherent passages (e.g., 500 tokens with 50-token overlap) suitable for embedding models and LLM context windows.
Embedding
A dense mathematical vector (e.g., 768 or 1536 floating-point numbers) produced by a neural encoder that maps semantic meaning into high-dimensional geometric space.
Cosine Similarity
A metric measuring the angle between two embedding vectors in multidimensional space. Used to calculate how semantically similar a user query is to an indexed text chunk.
ANN Search
Approximate Nearest Neighbor search. Fast algorithmic indexing (such as HNSW or ScaNN) designed to retrieve the top-k closest vectors in sub-linear time at enterprise scale.
Vector Database
A specialized storage engine (e.g., Vertex AI Vector Search, Qdrant, Pinecone) optimized for indexing, updating, and querying high-dimensional vectors with metadata filtering.
RAG
Retrieval-Augmented Generation. An architecture that dynamically retrieves external domain facts matching a query and injects them into the LLM's prompt context prior to answer generation.
Property Graph
A graph model where entities are Nodes (with labels and key-value properties) and relationships are directed Edges (also with types and properties). Standard in Neo4j.
Cypher
The declarative query language used by Neo4j and OpenCypher to express graph patterns, entity traversals, and multi-hop relationship pathfinding.
Knowledge Graph (KG)
A structured network of real-world entities (persons, shell companies, bank accounts) and their explicit relationships (OWNED_BY, TRANSFERRED_TO), serving as a deterministic ground truth.
GraphRAG
An advanced retrieval paradigm combining knowledge graph traversal (for relational context and multi-hop reasoning) with vector similarity (for narrative nuances) to answer complex queries.
