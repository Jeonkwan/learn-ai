Architecture Reference Document #03

Google Cloud AI & Data Architecture Cheat Sheet

A DevOps reference for Vertex AI, Document AI, BigQuery Vector Search, and IAM roles.

1. The Google Cloud AI Portfolio at a Glance

Google Cloud organizes its AI stack into managed platform services under the Vertex AI umbrella, alongside specialized document processing and data warehouse search engines.

GCP Service What It Is (DevOps Analogy) Primary Role in Unstructured AI Pipelines Typical Latency / SLA
Cloud Document AI Specialized OCR & Document Layout Microservice Extracts clean text, form key-values, and nested tables from scanned PDFs, bank statements, and invoices. 1s – 5s per document (Batch or Realtime API)
Vertex AI Model Garden Managed Model Registry & API Gateway Serves foundation models (Gemini 1.5 Pro / Flash) and embedding models (text-embedding-004). 50ms – 150ms for embeddings; streaming for LLM
Vertex AI Vector Search Managed High-Scale Distributed ScaNN Index Stores and searches millions of high-dimensional vectors with sub-5ms latency and metadata filtering. < 5ms p99 at 10,000+ QPS
BigQuery Vector Search SQL Engine with Vector Indexing (IVF / HNSW) Executes VECTOR_SEARCH() directly inside SQL queries alongside relational business tables. Seconds to minutes (Analytical / Batch queries)
Vertex AI Search Turnkey Managed Enterprise RAG Service Out-of-the-box ingestion, chunking, indexing, and generative answers without managing vector indexes manually. Managed end-to-end SLA

2. Key IAM Roles for AI Infrastructure

Follow the principle of least privilege when configuring Service Accounts for Cloud Run ingestion workers or GKE agents.

IAM Role Resource Scope Permissions Granted
roles/aiplatform.user Vertex AI Platform Call models (Gemini, text-embedding) and query Vector Search Index Endpoints.
roles/aiplatform.admin Vertex AI Platform Create/delete Vector Search indexes, deploy endpoints, update machine specs.
roles/documentai.apiUser Document AI Invoke Document AI processors (OCR, Form Parsers) for real-time and batch extraction.
roles/bigquery.dataViewer BigQuery Query BigQuery datasets and run VECTOR_SEARCH() SQL statements.

3. Essential `gcloud` CLI Commands

# 1. Print OAuth access token for raw curl testing
ACCESS_TOKEN=$(gcloud auth print-access-token)

# 2. Call Vertex AI text-embedding-004 via curl
curl -X POST \
  -H "Authorization: Bearer ${ACCESS_TOKEN}" \
  -H "Content-Type: application/json; charset=utf-8" \
  "https://us-central1-aiplatform.googleapis.com/v1/projects/${PROJECT_ID}/locations/us-central1/publishers/google/models/text-embedding-004:predict" \
  -d '{
    "instances": [
      { "content": "Subject opened structured accounts at branch 104." }
    ]
  }'

# 3. List deployed Vector Search Index Endpoints
gcloud ai index-endpoints list --region=us-central1

# 4. Process document via Document AI
gcloud documentai processors process PROCESSOR_ID \
  --location=us \
  --raw-document=path=sar_report.pdf,mime-type=application/pdf
