Lesson 0019 • Hybrid Architecture

Hybrid Query Routing & Unified Retrieval

Building the intelligent gateway that dispatches queries to Vectors, Knowledge Graphs, or SQL.

In a production AML intelligence portal, investigators do not type Cypher queries or choose vector algorithms manually. They type natural language questions into a single search box:

  • Query A: "Find whistleblower emails discussing luxury yacht kickbacks."
  • Query B: "Who are the beneficial owners of accounts that wired money to Cyprus entity 402?"
  • Query C: "Show me all suspicious wire transfers connected to suspects who discussed yacht kickbacks."

Notice that Query A requires Vector Search, Query B requires Knowledge Graph traversal (Cypher), and Query C requires both simultaneously. How does a production system route these requests automatically?

How the Router Classifies Queries

In production, you can implement the router using Gemini 1.5 Flash with Tool / Function Calling. In under 150 milliseconds, the model inspects the question and decides which backend tool to call:

// Router tool definition payload
{
  "tools": [{
    "functionDeclarations": [
      {
        "name": "query_vector_search",
        "description": "Call when searching unstructured text, tone, or descriptive themes.",
        "parameters": { "type": "OBJECT", "properties": { "semantic_query": { "type": "STRING" } } }
      },
      {
        "name": "query_knowledge_graph",
        "description": "Call when asking about entity networks, ownership hops, or transaction paths.",
        "parameters": { "type": "OBJECT", "properties": { "cypher_pattern": { "type": "STRING" } } }
      },
      {
        "name": "query_hybrid_engine",
        "description": "Call when combining textual themes with multi-hop entity connections."
      }
    ]
  }]
}

Fusing Vector and Graph Context in the Prompt

When a hybrid query is executed, the gateway passes both sources of truth into the final prompt:

[GROUNDED EVIDENCE FROM VECTOR REPOSITORY]:
- Whistleblower Email (Chunk #88): "Subject Viktor O. authorized wire for luxury yacht..."

[VERIFIED TOPOLOGY FROM NEO4J KNOWLEDGE GRAPH]:
- Path: (:Person {name: "Viktor O."}) -[:BENEFICIAL_OWNER]-> (:Company {name: "Apex Ltd"})
        -[:TRANSFERRED $1,500,000]-> (:Account {iban: "CY9910"}) -[:HELD_BY]-> (:Company {name: "Monaco Marine"})

SYNTHESIS: Viktor O. used his beneficial ownership in Apex Ltd to transfer $1.5M to Monaco Marine, corroborating the whistleblower email regarding yacht financing.
