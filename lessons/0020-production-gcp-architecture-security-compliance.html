Security & Banking Compliance Invariants

As a DevOps engineer operating in regulated banking environments, your infrastructure must satisfy strict audit controls:

  • VPC Service Controls (VPC-SC): Creates a cryptographic security perimeter around your Cloud Storage buckets, Document AI processors, and Vertex AI endpoints. Even if an attacker gains stolen IAM credentials, they cannot exfiltrate banking records outside the perimeter.
  • Private Service Connect (PSC): Eliminates public IP exposure. All communication between Cloud Run, Vertex AI Vector Search, and Neo4j stays strictly inside private VPC subnets.
  • Customer-Managed Encryption Keys (CMEK): All vectors, graph nodes, and documents are encrypted at rest using keys managed in Google Cloud KMS.
  • Immutable Audit Trails: Every query submitted by an investigator, including the retrieved chunks and generated response, is streamed to BigQuery with full tamper-evident Cloud Audit Logs for federal regulators (FinCEN/OCC).

Evaluating Retrieval Quality: The RAGAS Framework

How do you know if your pipeline is actually working or if retrieval quality is degrading over time? Never rely on manual vibe checks. Production systems automate evaluation using RAGAS (Retrieval Augmented Generation Assessment):

1. Faithfulness (Zero Hallucination)

Measures whether every single statement made by the LLM is mathematically grounded in the retrieved evidence chunks. Target: > 0.98.

2. Answer Relevance

Measures whether the generated brief directly addresses the investigator's question without extraneous filler. Target: > 0.90.

3. Context Precision (Signal-to-Noise)

Evaluates whether your vector index and re-ranker placed the true gold chunks at the top of the context window. Target: > 0.85.

4. Context Recall

Verifies whether all facts needed to answer the question were successfully retrieved from storage. Target: > 0.90.
